# 📚 StudyShare

## 📌 Project Overview
**StudyShare** is a web-based platform that allows students to upload, share, search, and access study materials such as notes, PDFs, and educational resources.

The system provides:
- User authentication
- Resource uploading
- Online notes search
- Local resource search
- Admin management features

The project is developed using:
- HTML
- CSS
- JavaScript
- LocalStorage & SessionStorage
